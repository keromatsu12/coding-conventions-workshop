# 第7章 パッケージ設計 — 悪い配置の例

⚠️ **このディレクトリは意図的に悪く作られています。** 実務で真似しないでください。

このディレクトリは、他の章と違って **コードの中身ではなく「置き方」そのもの** が題材です。
ファイルを1つずつ読むのではなく、**import 文だけを追いかけて** ください。

```
ch07-package/
├── shared/
│   ├── utils.ts
│   ├── constants.ts
│   ├── orderHelper.ts
│   ├── userHelper.ts
│   └── mailTemplate.ts
├── order/
│   ├── Order.ts
│   ├── internal/
│   │   ├── PriceTable.ts
│   │   └── constants.ts
│   └── services/
│       └── OrderService.ts
└── user/
    ├── User.ts
    └── UserService.ts
```

## 観察のしかた

1. 各ファイルの先頭の `import` を書き出して、矢印を引いてみてください。
2. 矢印がどこかで一周していないか確認してください。
3. `internal/` という名前のディレクトリに、どこから矢印が入ってきているか確認してください。
4. `shared/` に置かれているものが、本当に「全機能から使う共通部分」か考えてみてください。
